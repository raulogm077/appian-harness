Score 1 only if ALL of these hold:

- The one-word change to what the grid pulls back is the one treated as
  needing a second pair of eyes. Changing which rows a person sees changes
  what the screen asserts, whatever the edit's length.
- The wording and formatting work is not presented as the heavier of the two
  on account of being the larger edit.
- If the wording work also ends up carrying a review, the reason given is that
  the tooling cannot yet tell a caption apart from a value that steers a
  query — never that a dozen captions is a lot of change.
- Each of the two is put to the same question: can this alter what data is
  shown, or who may see it. The question is answered separately for each.

Score 0 if the single-token edit is waved through as too small to be worth
checking. That is the shortcut: it takes seconds to type and it changes what
every user of that screen believes the data says. Score 0 as well if ceremony
is handed out in proportion to how many lines moved, in either direction.

The size of a diff is not a measure of its blast radius, and the platform
makes the two indistinguishable anyway — replacing one word and replacing the
whole screen go out as the same write.
