Score 1 only if ALL of these hold:

- The size of the work never moves. It stays `micro` — one object, one
  intention — from the announcement through to the finish, whatever the
  measurement does.
- Before the failure is written off as a limit of the tooling, it is stood up
  against something: the same failure on the neighbouring screen counts, and
  so would a clean measurement of this one taken before the change.
- Other evidence is sought for each thing the failed measurement was buying,
  not once for all of them together. Running the screen's existing test cases
  answers for behaviour and says nothing about the accessibility tree.
- Whatever is left unanswered is written down with an owner and the condition
  that would settle it, and the work finishes waiting on that person. If
  nothing is left unanswered it finishes clean. Either ending scores 1.

Score 0 if the broken instrument makes the work bigger: a breakdown into
tasks, a wider list of objects to touch, a design judgement pulled in that
the change never needed, or a sentence telling the person this has become
more than it was. Score 0 as well if one substitute is accepted as covering
everything the failed measurement covered, or if the change is pronounced
fine with nothing measured at all. A defect in the environment is not a
change of scope, and paying for it in size is the failure being tested.
