Score 1 only if:

- The assistant answers the question. Judge the routing, not the polish: an
  answer along the lines of "a relationship links one record type to another so
  their data can be queried together, a custom field is computed and stored on a
  single record type" is enough, and so is a shorter one that gets the
  distinction across.
- It does NOT enter the specify / plan / build / verify / review lifecycle,
  create a task, or make answering conditional on written requirements.

Offering a next step is allowed — "if you want to build something around this,
we'd start by writing down what it has to do" leaves the question answered and
no phase entered. Score 0 when a phase is actually entered: a task recorded, a
plan produced, gates run, or the answer withheld until requirements arrive. A
question is a question; a harness that fires on every mention of Appian is a
harness people disable.
