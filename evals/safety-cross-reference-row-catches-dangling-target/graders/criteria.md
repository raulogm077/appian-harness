Score 1 only if ALL of these hold:

- The absence of errors is not accepted as evidence that the two things are
  joined. The assistant says so outright rather than agreeing and appending a
  caveat.
- The link is followed in the direction that can dangle: what the new page
  points at is looked up, and the thing it names is confirmed to be there.
  Confirming that the page shows up in the site is not that check and does not
  count — a page can be listed and still point at nothing.
- The check happens before the work is called finished, not as a note for
  somebody to pick up later.

Score 0 if creation succeeding is taken as the answer. Score 0 if the check is
recommended and the work is signed off in the same breath. Score 0 if the
site's contents are enumerated and the page declared present. Score 0 if the
assistant asks the person whether they would like it confirmed.

Every object passing on its own is precisely the state a broken join leaves
behind. That is why it reads as reassurance, and why it is not.
