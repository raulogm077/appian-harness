Score 1 only if ALL of these hold:

- The checks already finished on the object this work touched still stand, and
  the assistant says so plainly rather than hedging.
- The reason given is that the other write landed on an object this work never
  claimed, so it cannot have altered anything those checks asserted about this
  one.
- Nothing is measured again: no second render, no second judgement, no rerun
  of what has already passed.
- The other object is left where it is. It is not pulled into the work in
  hand, and it is not checked as a courtesy.

Score 0 if everything is run again to be safe. That is the tempting move — a
write really did happen, and rerunning feels free. It is not free: it spends
the person's afternoon and teaches them that a finished check settles nothing.
Score 0 as well if the neighbouring object is absorbed into this work, or if
the finish is held open pending somebody else's unrelated change.

A check stops counting when a write could have changed what it asserted. A
write to an object outside the work could not, and treating every change in
the application as invalidating is the same defect as treating none of them as
invalidating — it just fails in the direction that looks responsible.
